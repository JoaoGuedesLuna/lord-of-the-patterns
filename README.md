<h2>📜 Overview</h2>

<p style="text-align: justify;">
  <strong>Design patterns</strong> are proven, general-purpose solutions to recurring problems in software design.
  Instead of reinventing the wheel, these patterns offer templates to address common challenges in product flexible, maintainable way.
</p>
<p style="text-align: justify;">
  This repository contains practical implementations of design patterns categorized by their intent — <strong>Creational</strong>, <strong>Structural</strong>, and <strong>Behavioral</strong>.
  Each example reinforces fundamental object-oriented design principles, including variants of the classic patterns to show alternative approaches.
  All examples will now be illustrated using characters, items, and scenarios inspired by <strong>The Lord of the Rings</strong> 🏹🧝‍♀️🔥.
</p>

<h2>🏰 Categories of Patterns</h2>

<p style="text-align: justify;">
  Design patterns vary in complexity, purpose, and scale of applicability. They are commonly grouped into three broad categories based on their functionality.
</p>

<h3>🛡️ Creational Patterns</h3>

<p style="text-align: justify;">
  Creational patterns deal with object creation mechanisms. They abstract the instantiation process, making code more flexible and decoupled from specific classes.
</p>

<h3>🏹 Structural Patterns</h3>

<p style="text-align: justify;">
  Structural patterns explain how to assemble objects and classes into larger structures, while keeping them flexible and efficient.
</p>

<h3>🧙 Behavioral Patterns</h3>

<p style="text-align: justify;">
  Behavioral patterns are concerned with communication and responsibility between objects. They define how objects interact and assign responsibility effectively.
</p>

<h2>🧪 Unit Tests & Code Coverage</h2>

<p style="text-align: justify;">
  All unit tests for this project were implemented using <strong>JUnit</strong>, ensuring the correctness and reliability of each data structure and algorithm implementation.
</p>

  Code coverage analysis was performed with <strong>JaCoCo</strong>, allowing verification of how much of the codebase is exercised by the automated tests.
</p>

<p style="text-align: justify;">
  To generate the report, run:
</p>
<pre><code>mvn clean verify</code></pre>

<p style="text-align: justify;">
  After running the tests, the JaCoCo report can be found at:
</p>
<pre><code>target/site/jacoco/index.html</code></pre>

<p style="text-align: justify;">
  Then open the generated HTML file in your browser to explore detailed coverage metrics.
</p>
